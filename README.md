# Le juste prix !

Petit "Juste Prix" fait pour le fun en TypeScript.

<details>
  <summary>Voir les règles du jeu</summary>

  ### Choix du nombre :
  Le jeu choisit un nombre secret dans une plage définie entre 1 et 1000.

  ### Temps imparti :
  le joueur a 60 secondes pour trouver le bon nombre.

  ### Nombre d'essais limité :
  Le joueur n'a que 10 essais maximum pour trouver le bon nombre.

  ### Fin du jeu, le jeu peut se terminer de 3 façons différentes :
  1 - Le joueur trouve le bon nombre et remporte la partie 😊
  
  2 - Le joueur ne trouve pas le bon nombre dans le temps imparti et perd la partie 😢
  
  3 - Le joueur épuise ses 10 chances et perd la partie 😢
</details>
